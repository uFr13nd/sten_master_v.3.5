# MODEL PARITY — WEB v3.8 ↔ Google Sheets v3.7

## Основные правила

| Логика | Google Sheets v3.7 | WEB v3.8 |
|---|---|---|
| Наружные/межквартирные | цена конструкции × объём | `calcWall()` |
| Перегородки | цена конструкции × площадь | `calcPartition()` |
| Отделка | ставка отделки × площадь × этажи | `getFinishRate()` + category calc |
| Доставка | рассчитывается справочно | `deliveryCost`, **не входит** в `total` |
| Итог решения | работы + материалы + отделка | `total = costObj + finishCost` |
| Δ площади | 0 только при совпадении материал + отделка | `sameProjectSolution` |
| Стоимость выбранного решения | считается всегда | `changedByCategory[cat] = categories[cat].total` |
| Итого выбранных решений | сумма 3 категорий | `changedTotal = fullTotal` |

## Справочники

- Google Sheets остаётся master-data источником.
- `Работы` читаются по кодам `W-xxx`.
- `Материалы` читаются по кодам `M-xxx`, включая технические колонки A:S.
- Добавление материала через WEB пишет новую строку `Материалы!A:S` и назначает новый `M-xxx`.
- Полистиролбетонные конструкции фильтруются из публичного списка.
- Перегородки со статусом `Не проходит` фильтруются из публичного списка.
- Доборные элементы с нулевым вкладом не влияют на сумму.
