# STEN MASTER WEB v3.8.4

## Что исправлено

1. Исправлен обмен GitHub Pages → Apps Script через hidden form + `postMessage`.
   Старый frontend отправлял `bootstrap` через POST, а backend v3.8.x не разбирал поле `payload` как JSON-команду и не возвращал `postMessage`. Поэтому интерфейс оставался в `Fallback v3.8 · Google Sheets v3.7`.
2. В публичный bootstrap добавлены `previousPrice` и `changedAt` для справочников. В WEB у материалов выводится дата последнего зафиксированного изменения цены.
3. Добавлен централизованный запрос актуализации цен. Повторный запрос блокируется backend на 30 дней независимо от состояния кнопки в браузере.
4. Добавлен общий чат проекта с историей в листе `Чат`.
5. Массовое сохранение расценок v3.8.3 сохранено. Для цены batch-update записывает предыдущую цену, дату изменения, автора и строку в `Журнал_цен`.

## Что уже подготовлено в Google Sheets

- `Запросы_цен`
- `Чат`
- `История_изменений`
- `Материалы!E:G` для предыдущей цены, даты и автора

## Развёртывание backend

В Apps Script текущей таблицы:

1. В существующем backend переименовать только две функции:
   - `doGet` → `doGetLegacy`
   - `doPost` → `doPostLegacy`
2. Добавить новый файл `WEB_V384.gs` из этого репозитория.
3. Сохранить проект.
4. Обновить существующий Web App deployment новой версией, сохранив тот же URL.
5. Проверка: `.../exec?action=health` должна вернуть `3.8.4-web`.
6. После публикации открыть GitHub Pages и нажать `↻ Синхронизировать`.

`index.html` теперь загружает сохранённый интерфейс v3.8.3 и подключает `v384-patch.js`, поэтому расчётный движок и текущая верстка не переписывались.
