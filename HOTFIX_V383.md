# STEN MASTER WEB v3.8.3

## Изменено
- Удалены кнопки «Сохранить» у каждой строки централизованных расценок.
- Добавлена одна кнопка «Сохранить все изменения».
- Несохранённые изменения сохраняются в черновике при поиске, фильтрации и переключении вкладок.
- Изменённые строки подсвечиваются, рядом с кнопкой отображается число изменённых полей.
- При попытке закрыть страницу с несохранёнными изменениями браузер предупреждает пользователя.
- Backend получил `updateReferencesBatch`: все правки отправляются одной командой, а синхронизация баз выполняется один раз после пакета изменений.
- Добавление нового материала и загрузка сертификата остаются отдельными действиями, поскольку это одиночные операции, а не табличное массовое редактирование.

## Развёртывание
Заменить `Code.gs`, `app.js`, `index.html`, `styles.css`. Обновить существующее Apps Script deployment. `?action=health` должен вернуть `3.8.3-web`.
