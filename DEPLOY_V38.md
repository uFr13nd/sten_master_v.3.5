# Порядок обновления v3.8

1. Обновить `Code.gs` в Apps Script.
2. Запустить `setupWebV38()` один раз.
3. Обновить существующий Web App deployment, сохранив URL.
4. Проверить `?action=health` → `3.8-web`.
5. Опубликовать файлы frontend в GitHub `ufr13nd/sten-master`.
6. Открыть GitHub Pages и нажать `↻ Синхронизировать`.
7. В разделе `Система` должно быть `186 / 186`.
8. В `Администрирование` проверить вход, добавление тестового материала (при необходимости удалить строку вручную после теста) и загрузку тестового сертификата.
9. Сформировать PDF отчёт.
10. В `История цен` выбрать 2–3 материала и построить графики.
